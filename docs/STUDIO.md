# PURE Intelligence Studio + JEV

Studio คือหน้าผู้ช่วย AI ในแอป PURE (แท็บ Studio) โดย **JEV** เป็นตัวคัดกรองงาน ไม่ใช่โมเดลที่ฝึกใหม่

## JEV เลือกเส้นทางอย่างไร

| ประเภทงาน | ส่งต่อให้ | เงื่อนไข |
|---|---|---|
| ค้นเว็บ / ข่าวล่าสุด | Hermes Agent | ต้องติ๊ก "อนุญาตบริการออนไลน์" |
| รูปภาพ (OCR) | โมเดล Ollama ที่มี `vision` | เลือกตัวเล็กสุดก่อน |
| PDF | Gemini | ต้องอนุญาตบริการออนไลน์ |
| แชต / เขียน / วางแผน | โมเดล Ollama ในเครื่อง (เล็กสุดก่อน) | ถ้าไม่มี → Gemini เมื่ออนุญาต |
| ข้อความสั้นเช่น "ช่วยหน่อย" | ป๊อปอัป "ให้ JEV ช่วยเลือก" | ผู้ใช้กดเลือกประเภทงานเอง |

`translategemma` ถูกกันออกจากงานแชตทั่วไป เพราะเป็นโมเดลแปลภาษา

## ความปลอดภัย
- ต้องล็อกอิน จำกัด 8 คำขอ/นาที/บัญชี และรันได้ครั้งละ 1 งานต่อบัญชี (รวมทั้งระบบ 2 งาน)
- ไฟล์ไม่เกิน 8 MB ตรวจ magic bytes ของ PNG/JPG/WebP/PDF ข้อความ TXT/MD/CSV/JSON ไม่เกิน 120 KB
- ไฟล์แนบถูกส่งเป็นข้อมูล ไม่ใช่คำสั่งระบบ
- Hermes รันแบบ `--safe-mode` เฉพาะ toolset `web` ไม่อ่านไฟล์หรือแชตส่วนตัว
- ประวัติเก็บ 20 รายการล่าสุดต่อบัญชี ลบได้จากหน้า Studio
- Ollama ประมวลผลบนเครื่องเซิร์ฟเวอร์ ส่วน Gemini/Hermes ส่งคำถามหรือไฟล์ให้บริการออนไลน์

## ตัวแปรใน .env
`OLLAMA_URL` (ค่าเริ่มต้น `http://127.0.0.1:11434`), `HERMES_BIN`, `HERMES_PROVIDER`, `HERMES_MODEL`, `GEMINI_API_KEY`

## ทดสอบ
- `node --test tests/studio.test.js` ทดสอบ JEV และ Studio API ด้วย Ollama/Hermes จำลอง
- `node tools/probe-studio-live.mjs` ยิง JEV กับ Ollama ตัวจริงบนเซิร์ฟเวอร์ชั่วคราว ไม่แตะข้อมูลจริง

## ผลตรวจล่าสุด
- 33/33 เทสต์ผ่าน
- JEV เลือก Qwythos-9B ใน Ollama ตอบจริงภายใน 6–11 วินาที
- แก้ system prompt หลังพบโมเดลตอบมั่วว่า PURE เป็นโมเดลของบริษัทอื่น
- ยังไม่ได้ทดสอบ OCR ภาพจริงและค้นเว็บผ่าน Hermes จริงในรอบนี้
