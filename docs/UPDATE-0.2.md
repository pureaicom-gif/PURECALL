# PURE 0.2 — AI companions & nearby

## ฟีเจอร์ที่เพิ่ม
- เลือกสัตว์ 8 ชนิด: แมว หมา ไดโนเสาร์ สิงโต เต่า กระต่าย จิ้งจอก เพนกวิน
- สกิน 5 แบบ: Snow, Midnight, Panda, Space explorer, Little wizard
  ซื้อด้วยเหรียญในเกมครั้งเดียว เปลี่ยนใส่ได้ทุกชนิด ไม่ใช้เงินจริง
- บุคลิก 3 แบบ: ขี้เล่น อ่อนโยน ช่างสงสัย
- แตะสัตว์เพื่อให้ตอบสนอง, โบกมือ, ลูบหัว, เต้น, นอน; ปากขยับระหว่างอ่านคำตอบ
- ห้อง AI ของสัตว์เลี้ยง: พิมพ์คุย หรือกดอัดเสียงสูงสุด 20 วินาทีแล้วกดส่ง
  Gemini ประมวลผลเสียง WAV และตอบเป็นข้อความ จากนั้นระบบเสียงของเครื่องอ่านออกเสียง
- Android ใช้ TextToSpeech ของระบบ ต้องมีเสียงภาษาไทยติดตั้งไว้
  เบราว์เซอร์ใช้ SpeechSynthesis; ปิดอ่านออกเสียงหรือหยุดเสียงได้
- ประวัติคุยกับสัตว์เก็บล่าสุด 10 คู่ข้อความ ล้างได้ และไม่ปนกับแชตเพื่อน/ผู้ช่วย
  ประวัติแสดงอินพุตเสียงเป็น “[ข้อความเสียง]” ไม่เก็บเสียงต้นฉบับ ไม่ใช่ระบบถอดเสียงถาวร
- PURE AI เป็นห้องผู้ช่วยแยกต่างหาก เปิดได้จากหน้าแชตหรือโปรไฟล์
  จำข้อความล่าสุด 10 คู่ และล้างประวัติได้ ไม่อ่านข้อความเพื่อน/สัตว์/ตำแหน่ง
- ค้นพบผู้ใช้ใกล้ตัวแบบทั้งสองฝ่ายเปิดใช้: ยินยอมก่อนส่งตำแหน่ง,
  ปัดพิกัดหยาบประมาณ 0.01 องศา, แสดงช่วงระยะทางไม่เกิน 50 กม., หมดอายุใน 1 ชั่วโมง
  ปิดค้นพบได้ทันที ไม่ติดตามเบื้องหลัง และไม่แสดงผู้ใช้ที่บล็อกกัน
- ส่งคำขอเป็นเพื่อนจากรายชื่อใกล้ตัว แล้วให้อีกฝ่ายรับ/ปฏิเสธก่อนเริ่มคุย

## เปิดใช้งาน
1. อัปเดตเซิร์ฟเวอร์ด้วยแพ็กใหม่ โดยรักษา `.env` และ `data/` เดิม
2. ติดตั้ง `PURE-0.2.0-debug.apk` ทับ 0.1 (application ID และ debug signing key เดิมในเครื่องนี้)
3. ฐานข้อมูลเพิ่มตาราง/คอลัมน์อัตโนมัติ ไม่ลบผู้ใช้ เหรียญ หรือข้อความเดิม
4. ใส่ Gemini key ใหม่และโมเดลที่รองรับข้อความ/เสียงใน `.env` แล้วรีสตาร์ต
5. ไมค์และตำแหน่งต้องใช้ HTTPS หรือ localhost ที่ปลอดภัย

การโต้ตอบด้วยท่าทาง/คำทักทายสำเร็จรูปเป็น logic ในแอป มีป้ายแยกจากคำตอบ Gemini
หากไม่มีคีย์จะไม่แสดงคำตอบสมมติว่าเป็น AI จริง
เสียงเป็นการคุยแบบผลัดกันพูด (กดอัด → ส่ง → ตอบ) ยังไม่ใช่ Gemini Live แบบ full duplex
สัตว์เลี้ยง AI และค้นหาคนใกล้ตัวต้องมีอินเทอร์เน็ต/เซิร์ฟเวอร์ ไม่ใช่โหมด Nearby ออฟไลน์

## ทดสอบ
- `npm test`: 18 tests ผ่าน รวมสกินไม่หักเหรียญซ้ำ, สิทธิ์ประวัติ AI,
  แยกห้อง AI, WAV upload, consent/expiry/blocking ของ nearby และ friend requests
- `node tests/ui.mjs`: ฟีเจอร์เดิมยังผ่านทั้งแชต ไฟล์ WebRTC กล้องจำลอง และสัตว์เลี้ยง
- `node tests/companion-ui.mjs`: 8 species, skin purchase, personality, ข้อความ/เสียงไมค์จำลอง,
  ส่ง WAV ให้ provider mock, dispatch ไป TTS mock, nearby geolocation fixture, คำขอและผู้ช่วยแยกห้อง
- APK 0.2 build ผ่าน; ยังต้องทดสอบเสียงภาษาไทย กล้อง/ไมค์ และตำแหน่งบนมือถือจริง
- การตอบ Gemini และคุณภาพเสียงภาษาไทยจริงยังไม่ได้ยืนยัน เพราะยังไม่มีคีย์ใหม่และเครื่องจริง
