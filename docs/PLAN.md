# PURE · แผนงานและแบบระบบ

อัปเดต 0.2 ทำตาม [UPDATE-0.2.md](UPDATE-0.2.md): สัตว์ 8 ชนิด, 5 สกิน, บุคลิก AI,
คุยข้อความ/เสียงแบบผลัดกันพูด, ค้นพบผู้ใช้ใกล้ตัวโดยสมัครใจ และผู้ช่วย AI แยกห้อง
รายละเอียดด้านล่างบันทึกขอบเขตฐานของ 0.1

เวอร์ชัน 0.1 — แอป Android แบบ WebView + responsive web client, Node.js 24, SQLite และ Socket.IO

เพิ่มตามคำขอ: Nearby native สำหรับข้อความตัวต่อตัวผ่าน Wi-Fi/ฮอตสปอต หรือ Bluetooth
มือถือทั้งสองต้องติดตั้ง PURE; Wi-Fi ใช้ TCP และกรอก IP, Bluetooth ใช้ secure RFCOMM กับอุปกรณ์ที่จับคู่แล้ว
มีรหัสจับคู่และยืนยันการรับข้อความ โหมดนี้ไม่ต้องใช้บัญชีหรือเซิร์ฟเวอร์ แต่ไม่เก็บประวัติถาวร

## แนวทางออกแบบ
พื้น #0b0c0e, การ์ด #151619, เส้น #282a2e, ตัวอักษร #f6f6f6 และเทารอง #96999f
โลโก้ PURE เป็นตัวอักษรเรขาคณิต ใช้ไอคอน SVG ของโปรเจกต์ ไม่มีรูปบุคคลหรือบทสนทนาปลอมในบัญชีจริง
เดสก์ท็อปมี sidebar / รายการแชต / ห้องสนทนา; มือถือมี bottom navigation 4 แท็บ
สถานะว่าง บันทึกผิดพลาด โหลดข้อมูล และการเชื่อมต่อขาดต้องแสดงชัดเจน

## ขอบเขตเวอร์ชันแรก
- สมัคร/เข้าสู่ระบบ, session ฝั่งเซิร์ฟเวอร์, ชื่อและ PURE ID
- ค้นหาเพื่อน, ขอเป็นเพื่อน, รับ/ปฏิเสธ, บล็อก
- แชตส่วนตัว, ประวัติย้อนหลัง, สถานะอ่าน, กำลังพิมพ์, presence, ส่งไฟล์จำกัด 25 MB
- WebRTC เสียง/วิดีโอตัวต่อตัว, signaling ตรวจมิตรภาพ, รับ/ปฏิเสธ/วางสาย, mute และ camera toggle
- เกมสัตว์เลี้ยงแมว/หมา 2D บน Canvas, ค่าสถานะ, เหรียญ, กิจกรรม, ของแต่งห้องและเยี่ยมเพื่อน
- Gemini แบบ opt-in: ส่งเฉพาะ prompt ที่กรอก, สแกนรายการโมเดลทุก 24 ชั่วโมง, เลือกใช้รุ่นที่ตั้งค่า
- APK ทดสอบและชุดรันเซิร์ฟเวอร์ Windows / Docker พร้อม HTTPS proxy

## ขอบเขตถัดไป
FCM + native incoming call UI/foreground service สำหรับสายขณะปิดแอป, push ขณะออฟไลน์,
group chat/calls, E2EE สำหรับข้อความ, QR เพิ่มเพื่อน, avatar upload, reaction/reply, switch camera,
mini-games เพิ่มเติม, reporting/moderation dashboard, migration PostgreSQL + object storage เมื่อเพิ่มผู้ใช้
ฟีเจอร์ในรายการนี้ยังไม่ใช่ส่วนที่รับรองว่าทำงานใน 0.1

## เกณฑ์รับงาน
ทดสอบบัญชีสองคน: เพิ่มเพื่อน → รับคำขอ → ส่งข้อความ/ไฟล์ → รับแบบ realtime → เปิดอ่าน
บุคคลที่สามเข้าถึงข้อความ/ไฟล์ไม่ได้; session หมดอายุหรือ logout ใช้ไม่ได้
เหรียญและค่าสัตว์ต้องตรวจฝั่งเซิร์ฟเวอร์; ใช้ action ถี่เกินกำหนดไม่ได้
ทดสอบ signaling และ browser media; ทดสอบสอง Android จริงบน Wi-Fi/4G ก่อนใช้ production
สร้าง APK ได้ไม่ได้หมายความว่าทดสอบกล้องและเสียงบนโทรศัพท์จริงแล้ว

## การติดตั้งจริง
ต้องมี domain + HTTPS ที่เชื่อถือได้ และ TURN พร้อม secret ของผู้ดูแล
SQLite เหมาะกับเซิร์ฟเวอร์เดียว สำรองฐานข้อมูลและ uploads ร่วมกันขณะหยุดระบบ
แชตไม่ได้ E2EE; ผู้ดูแลเซิร์ฟเวอร์เข้าถึงข้อมูลได้; WebRTC เข้ารหัส media ตามมาตรฐาน
รุ่น Gemini ใหม่แสดงใน catalog แต่ไม่เปิดใช้เองเพื่อไม่ให้ค่าใช้จ่าย/ความสามารถเปลี่ยนเงียบๆ
