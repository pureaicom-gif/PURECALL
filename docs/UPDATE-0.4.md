# PURE 0.4 — แชท เพื่อน และผู้ช่วย AI

- ปรับหน้าแชท เพื่อน โปรไฟล์ ผู้ช่วย AI และหน้าการโทรเป็นโทนดำขาว พร้อมหน้าจอมือถือและ focus สำหรับคีย์บอร์ด
- กรองบทสนทนาทั้งหมด / ยังไม่อ่าน / ออนไลน์ และแสดงจำนวนคำขอเพื่อนใหม่ในเมนู
- เก็บข้อความร่างแยกตามบัญชีและเพื่อนใน sessionStorage ของแท็บปัจจุบัน คงอยู่เมื่อรีเฟรช ล้างร่างที่ส่งสำเร็จ ไม่ซิงก์ข้ามเครื่อง
- ค้นหาข้อความและเลือกดูเฉพาะไฟล์ในข้อความที่โหลดแล้ว หากต้องการค้นหาข้อความเก่าให้โหลดข้อความก่อนหน้าเพิ่ม
- หน้าเพื่อนแสดงจำนวนเพื่อน ออนไลน์ และคำขอรับเข้า พร้อมคัดลอก PURE ID
- ผู้ช่วย AI มีหัวข้อเริ่มสนทนาให้เลือก การเลือกจะกรอกช่องข้อความ ผู้ใช้กดส่งเอง
- สัตว์เลี้ยง 16 ชนิดและฟังก์ชันเดิมคงอยู่

ตรวจสอบ: npm test ผ่าน 18 tests; tests/ui.mjs ผ่านแชท/ไฟล์/WebRTC/สัตว์เลี้ยงบนเดสก์ท็อปและมือถือ; tests/companion-ui.mjs ผ่านทุกชนิดสัตว์/เสียงจำลอง/ใกล้เคียง/AI; tests/workspace-ui.mjs ผ่านตัวกรอง ร่างแยกห้องหลังรีเฟรช การล้างร่าง การค้นหาข้อความและไฟล์ หัวข้อ AI และตรวจหน้าจอไม่มีแนวนอนล้น
