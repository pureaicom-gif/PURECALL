# PURE 0.7.0 — Photo Studio & PURE Originals

## ใช้งาน
เลือกเพื่อนหรือกลุ่ม แล้วกดแนบรูปเพื่อเปิด Photo Studio ปรับโทน/แสง/สี หมุนและเทียบต้นฉบับ จากนั้นกด “ใช้รูปนี้” จึงอัปโหลดและส่ง รูปใหญ่ย่อด้านยาวไม่เกิน 2048px และเก็บความโปร่งใสสำหรับ PNG ปิดหน้าต่างหรือกดยกเลิกจะไม่ส่งภาพ

ปุ่ม “ให้ Gemini ปรับภาพ” ส่งภาพที่กำลังปรับให้ Google โดยสมัครใจ ผลลัพธ์กลับมาให้ตรวจอีกครั้งก่อนส่ง บริการนี้ต้องมี API key และโมเดลภาพที่บัญชีใช้ได้ หากโควตาหรือบริการไม่พร้อมยังใช้ฟิลเตอร์ในเครื่องได้ ไม่มีการส่งภาพให้บริการสร้างภาพอื่นแทน

สติกเกอร์ PURE Originals 10 แบบเป็นกราฟิก SVG ของแอป ไม่ใช่อีโมจิ เมื่อส่งจะสร้าง PNG โปร่งใสที่แสดงได้ทั้งเว็บและ Android มีการป้องกันข้อความซ้ำเมื่อกดลองส่งอีกครั้ง ไฟล์กลุ่มผูกกับกลุ่มและตรวจสมาชิกก่อนเข้าถึง

## รวมการพัฒนาก่อนหน้า
ไทม์ไลน์/Reels อัปโหลดไม่เกิน 60 MB, Like/Comment, ค้นหาและแก้โพสต์, ลบความคิดเห็นตามสิทธิ์, โปรไฟล์/Bio, AI ชวนคุยใต้โพสต์, QR เพิ่มเพื่อน, เซสชัน 180 วัน, เสียงแจ้งเตือนในเครื่อง, สลับลำโพง Android และเลขา AI พร้อมความทรงจำเฉพาะบัญชี

ระบบต่อสู้/ผจญภัยถูกนำออก รวมตารางเดิมเมื่อเปิดฐานข้อมูล เก็บสัตว์เลี้ยง การดูแล สกินและการคุยกับ AI ไว้ สำรองฐานข้อมูลก่อนอัปเกรด

## การตรวจสอบ
- ชุดทดสอบ Node: บัญชี เพื่อน ข้อความ การโทร ไฟล์ส่วนตัว กลุ่ม เซสชัน ไทม์ไลน์ Reels และสิทธิ์การแก้ไข
- Playwright: เข้าระบบค้างไว้ QR ที่ถอดรหัสได้จริง ไทม์ไลน์และหน้ามือถือ สติกเกอร์ส่งถึงอีกบัญชีทันทีทั้งแชตส่วนตัว/กลุ่ม ปรับรูปก่อนส่ง และเรียก AI เฉพาะเมื่อกด
- ทดสอบ Photo Studio: ขนาดภาพ หมุน ฟิลเตอร์ ความโปร่งใส ยกเลิก กลับโฟกัส และปฏิเสธไฟล์เสีย
- ทดสอบ Gemini image แบบจำลองผู้ให้บริการ: endpoint ของ Google, inline image, MIME และการจัดการผลลัพธ์ผิดรูปแบบ ยังไม่ได้ยืนยันคุณภาพภาพจริงจากบัญชีผู้ใช้
- Gemini Live ทดสอบระบบ relay/แยกความทรงจำ/interrupt ด้วย upstream จำลอง และ probe โมเดล native audio จริงได้เสียงกลับ 39 packets แต่ยังไม่ได้ทดสอบโทรบนมือถือจริงสองเครื่อง
- Android debug APK สร้างด้วย Gradle สำเร็จ ไม่ใช่ไฟล์ release สำหรับเผยแพร่ Play Store

## ติดตั้ง/อัปเดต
ปิดเซิร์ฟเวอร์เดิม สำรองโฟลเดอร์ data และ .env แล้วแทนที่ไฟล์โปรแกรมจาก PURE-Server-Windows.zip รักษา data/.env ของเดิมไว้ รัน START-SERVER.cmd หรือ START-ONLINE.cmd ติดตั้ง PURE-0.7.0-debug.apk ทับรุ่นเดิมที่ใช้ signing key เดียวกัน

ใช้ URL เดิมเสมอเพื่อรักษาคุกกี้ การเปลี่ยน IP หรือ URL ของ temporary tunnel เป็นเว็บไซต์คนละต้นทางและต้องเข้าสู่ระบบอีกครั้ง การโทร/ไมค์ต้องใช้ HTTPS; STUN อย่างเดียวไม่รับประกันข้ามทุกเครือข่าย ต้องตั้ง TURN สำหรับเครือข่ายที่จำกัด

แพ็กเกจไม่รวม API key, ฐานข้อมูลจริง หรือรหัสผ่านแอดมิน เปิดเซิร์ฟเวอร์ค้างไว้เพื่อใช้งานออนไลน์ โหมด Wi-Fi/Bluetooth ออฟไลน์ยังเป็นข้อความแยกจากแชตออนไลน์

## 0.7.1 — เลขา AI Live
เพิ่มเลือกเสียง Kore/Puck/Aoede, คำทักทายอัตโนมัติเมื่อเริ่มสาย, เวลาในสาย, สถานะฟัง/พูด และ audioStreamEnd เมื่อปิดไมค์ ตรวจ HTTPS และสิทธิ์ไมโครโฟนก่อนเริ่มสาย คีย์อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น

ทดสอบ API key ที่ตั้งไว้กับ Gemini Live จริง ได้เสียงตอบภาษาไทยกลับ 38 packets และทดสอบหน้าเว็บด้วยไมค์จำลอง: PCM upload, เลือกเสียง, คำทักทาย, จับเวลา, ปิดไมค์และวางสาย ผ่านครบ ยังไม่ได้ทดสอบเสียงจากไมค์มือถือจริง
