# PURE — สัตว์เลี้ยงครบ 16 ชนิด

ตรวจและปรับปรุงจากโปรเจกต์รุ่น 0.3 ที่มีอยู่ โดยรักษาสกินและชนิดสัตว์ทั้งหมดเดิม

## รายการสัตว์
แมว, หมา, ไดโนเสาร์, สิงโต, เต่า, กระต่าย, จิ้งจอก, เพนกวิน,
แพนด้า, หมี, แฮมสเตอร์, โคอาลา, ลูกเจี๊ยบ, เป็ด, กบ, นกฮูก

แต่ละชนิดมีรูปร่างที่ต่างกัน คำทักทาย ความชอบ ลักษณะนิสัย และค่าจังหวะ/ระดับเสียงของตัวเอง
Gemini ได้รับข้อมูลชนิดสัตว์และลักษณะนิสัยร่วมกับบุคลิกที่ผู้ใช้เลือก
ตัวอย่าง: เต่าพูดช้าและใจเย็น, แฮมสเตอร์พูดไวและกระฉับกระเฉง, สิงโตพูดจังหวะหนักแน่น
ไม่ได้เป็นการโคลนเสียงคน และคุณภาพเสียงยังขึ้นกับเสียงภาษาไทยของระบบ

## สิ่งที่เก็บรายละเอียด
- ตาแพนด้าอ่านชัดในสกินมืดและสกินทอง
- ปากเป็ดแบน ต่างจากจะงอยปากลูกเจี๊ยบ/เพนกวิน/นกฮูก
- กระต่ายมีหางปุย ไม่ใช้หางยาวของแมว
- เพนกวินมีขนสีเข้ม พุงสว่าง และปีกที่โบกได้
- เต่ามีกระดอง ขา และการโบกขาเฉพาะตัว
- ไดโนเสาร์มีคอ หาง หนาม และแขนสั้น
- สิงโตมีแผงคอ, จิ้งจอกมีปลายหาง, แฮมสเตอร์มีแก้มและฟันคู่
- สกินดอกไม้ใช้รูปทรงที่วาดใน Canvas จึงไม่ขึ้นกับฟอนต์อีโมจิของเครื่อง
- ท่าทาง 8 แบบ: ปกติ, โบกมือ, ลูบหัว, เต้น, พูด, นอน, กินอาหาร, อาบน้ำ
- กินอาหาร/อาบน้ำ/เล่น/นอนเชื่อมกับกิจกรรมที่บันทึกบนเซิร์ฟเวอร์

## การตรวจสอบ
`node tests/pet-matrix.mjs` ตรวจ 16 ชนิด × 7 สกิน × 8 ท่าทาง = 896 ภาพ
ตรวจว่าชนิดสัตว์ต่างกัน, แต่ละท่าทางเปลี่ยนภาพจริง, metadata ครบ และไม่มี Canvas/page errors
ตรวจภาพแกลเลอรีทั้งสกินขาว ดำ แพนด้า อวกาศ พ่อมด มงกุฎ และดอกไม้

ดูภาพเคลื่อนไหวโดยไม่ต้องมีบัญชี: `/pet-gallery.html`
หน้าแกลเลอรีเป็นภาพตัวอย่าง การเลือกชนิด/ซื้อสกินจริงทำในห้องสัตว์เลี้ยงหลังเข้าสู่ระบบ

เซิร์ฟเวอร์เครื่องนี้ตั้ง Gemini แล้ว และสแกนพบ 40 โมเดลที่รองรับ generateContent
ทดสอบ API จริงผ่าน gemini-3.6-flash สำเร็จทั้งข้อความบุคลิกไดโนเสาร์และไฟล์ WAV เงียบสำหรับตรวจเส้นทางรับเสียง
แพ็กเซิร์ฟเวอร์ไม่รวม API key ผู้ติดตั้งเครื่องใหม่ต้องตั้งค่าเอง
การคุยเสียงเป็นกดอัดแล้วส่ง ไม่ใช่ full-duplex; native Android TTS ถูกทดสอบว่าเรียกเครื่องยนต์และได้ callback เริ่มพูด
การทดสอบ UI ครบ 16 ชนิดใช้ provider จำลอง ส่วน API จริงตรวจสองคำขอข้างต้น ยังไม่ได้ประเมินการฟังเสียงพูดจริงหรือคุณภาพเสียงบนมือถือทุกรุ่น
