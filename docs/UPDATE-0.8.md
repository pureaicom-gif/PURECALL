# PURE 0.8.0 — Moments & Translation

- หน้าไทม์ไลน์ใช้กราฟิก PURE แบบ SVG พร้อมรูปตัวอย่างที่ออกแบบสำหรับแอป
- เปิด /timeline-preview.html เพื่อทดลองกดถูกใจ คอมเมนต์ โพสต์รูปและวิดีโอ ข้อมูลอยู่ในหน้านี้เท่านั้น รีเฟรชเพื่อเริ่มใหม่ ไม่โพสต์เข้าบัญชีจริงและไม่เรียก AI
- ไทม์ไลน์จริง: แต่งรูปก่อนโพสต์ แสดงเปอร์เซ็นต์อัปโหลด เก็บข้อความร่าง ป้องกันโพสต์ซ้ำเมื่อลองใหม่ รองรับ Reels MP4/WebM และตรวจสิทธิ์ก่อนสตรีม
- แชต: เปิด “แปลอัตโนมัติ” แล้วเลือกภาษา ไทย อังกฤษ ญี่ปุ่น เกาหลี จีน ฝรั่งเศส เยอรมัน หรือสเปน ส่งข้อความที่ได้รับให้ Gemini แปล แสดงใต้ต้นฉบับ การตั้งค่าแยกบัญชี แปลข้อความล่าสุดไม่เกิน 30 รายการที่โหลดอยู่ รองรับแชตส่วนตัวและกลุ่ม ตรวจสิทธิ์ก่อนใช้ผลแปลที่แคชไว้
- ข้อความรอส่ง: เก็บข้อความตัวอักษรในเครื่องได้ 100 รายการต่อบัญชี เมื่อเน็ตกลับจะส่งด้วย clientId เดิมเพื่อป้องกันซ้ำ มีสถานะรอส่งและลองใหม่เมื่อสิทธิ์เปลี่ยน ไฟล์/รูปยังไม่เข้าคิวออฟไลน์ และไม่สามารถเปิดหน้าแอปใหม่โดยไม่มีเซิร์ฟเวอร์ได้

## ผลทดสอบ
ชุดทดสอบ Node, Playwright สำหรับการแปล/ความเป็นส่วนตัว, เน็ตหลุดและการส่งใหม่, โพสต์รูปจริง, อัปโหลด WebM ที่มีเฟรมภาพและเล่น Reels, ตัวอย่างไทม์ไลน์ที่ตอบสนองบนจอมือถือ/เดสก์ท็อป ทดสอบ Gemini จริงด้วยข้อความทักทายภาษาอังกฤษและได้รับคำแปลไทยกลับมา

ยังไม่มีมือถือเชื่อมต่อสำหรับทดสอบฮาร์ดแวร์จริง และตามที่ผู้ใช้เลือก จะทำ Push Notification เมื่อปิดแอปภายหลังเมื่อมี Firebase การสำรองอัตโนมัติและโควตาค่าใช้จ่าย AI ต่อบัญชียังไม่รวมในรุ่นนี้

ติดตั้ง APK debug 0.8.0 และอัปเดตเซิร์ฟเวอร์คู่กัน เก็บ data และ .env เดิมไว้ API key ไม่รวมในแพ็กเกจ การโทรต้องใช้ HTTPS บนมือถือ
