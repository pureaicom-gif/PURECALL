# PURE 0.5 — ประลองกับเพื่อนและผจญภัย

## เล่นกับเพื่อน
1. เพิ่มเพื่อนและรออีกฝ่ายรับเป็นเพื่อน
2. เปิดเมนู **ผจญภัย** ทั้งสองคน แล้วกด **ท้าประลอง** ข้างชื่อเพื่อน
3. เพื่อนกด **รับคำท้า** จากนั้นผู้ส่งคำท้าเริ่มก่อน ผลัดกันเลือกทักษะ

สนามอัปเดตทุก 3 วินาทีขณะเปิดหน้า ใช้อินเทอร์เน็ต/การเชื่อมต่อกับเซิร์ฟเวอร์ ไม่รองรับการประลองผ่าน Bluetooth ในรุ่นนี้
ทั้งสองฝ่ายมี HP 110 และโจมตี 16 เท่ากัน สกิน เลเวล และเหรียญไม่เพิ่มความได้เปรียบ ไม่มีเดิมพัน ไม่มีรางวัลเหรียญจากการสู้กับเพื่อน
ทุกชนิดมีชื่อท่าประจำตัว ใช้กติกาพลังเดียวกัน: โจมตีเพิ่มพลัง 1, ตั้งรับลดความเสียหายครั้งต่อไปเหลือ 45% และเพิ่มพลัง 1, ท่าพิเศษใช้ 2 พลังสร้างความเสียหาย 1.9 เท่า, ฟื้นฟูใช้ 2 พลังเพิ่ม HP สูงสุด 28
ครบ 100 เทิร์นเสมอ คำท้า/สนามที่ไม่เคลื่อนไหว 24 ชั่วโมงหมดอายุ ออกจากสนามไม่มีรางวัล การบล็อกยกเลิกสนามเมื่อระบบตรวจครั้งถัดไป

## ผจญภัย
5 ด่านปลดล็อกตามลำดับ: ทุ่งหญ้า → ป่าแสงจันทร์ → ทะเลสาบ → ยอดเขา → หุบเขาดึกดำบรรพ์
ศัตรูควบคุมด้วยกติกาเกม ไม่เรียก Gemini แต่ละด่านมี HP/พลังโจมตีเพิ่มขึ้น
ผ่านครั้งแรกได้เหรียญและ EXP บันทึกในบัญชี เล่นซ้ำได้แต่ไม่รับรางวัลซ้ำ
ทุกด่านที่ผ่านเพิ่ม HP 20 และโจมตี 3 ให้การผจญภัยครั้งต่อไปเท่านั้น
สัตว์ไม่สูญหายและไม่มีบาดเจ็บถาวรเมื่อแพ้

## การบันทึกและตรวจสอบ
สถานะสนามและลำดับเทิร์นบันทึก SQLite กลับมาเล่นต่อได้หลังรีเฟรชหรือรีสตาร์ตเซิร์ฟเวอร์
เซิร์ฟเวอร์ตรวจเจ้าของสนาม ความเป็นเพื่อน การตอบรับ เทิร์น และพลังทักษะ การส่งเทิร์นเดิมซ้ำถูกปฏิเสธ รางวัลกับผลการต่อสู้บันทึกใน transaction เดียว

- npm test ผ่าน 20 tests รวมการผ่านครบ 5 ด่าน ไม่แจกเหรียญซ้ำ คำท้า/ความเป็นส่วนตัว/เทิร์นผิด การบล็อกและรีสตาร์ต
- tests/adventure-ui.mjs ใช้สองบัญชีทดสอบการท้า รับ ผลัดกันโจมตี/ตั้งรับ อัปเดตอีกเครื่อง รีเฟรชกลับสนาม รับรางวัล และกลับไปดูแลสัตว์เลี้ยง
- tests/ui.mjs ตรวจแชท ไฟล์ WebRTC และระบบสัตว์เลี้ยงเดิม
- ภาพเดสก์ท็อป/มือถืออยู่ใน docs/screenshots/30-adventure-map.png ถึง 33-adventure-victory.png
